# Estamparia Expansão — site institucional

Site de página única da Estamparia Expansão (Salto/SP), fábrica de uniformes e camisetas personalizadas desde 2020.

- HTML, CSS e JavaScript puros, sem build.
- Formulário de orçamento que abre o WhatsApp da loja com a mensagem pronta.
- Pronto para GitHub Pages.

## Estrutura

```
index.html          página completa (estilos e script inline)
assets/
  logo-selo.png     selo circular (fundo preto)
  logo-branco.png   logo em branco, fundo transparente
  logo-preto.png    logo em preto, fundo transparente
  simbolo-branco.png  símbolo "EE" isolado
  favicon.png
  *.jpg             fotos de produtos e fachada (retiradas do Instagram, baixa resolução)
```

## Publicar no GitHub Pages

1. Envie este repositório para o GitHub.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O site fica em `https://<usuario>.github.io/<repositorio>/`.

## Antes de entregar ao cliente

- Confirmar se o endereço R. Monsenhor Couto, 494 ainda é o atual.
- Trocar as fotos por versões originais em alta resolução.
- Confirmar horário de funcionamento e se há pedido mínimo.
- Configurar domínio próprio (ex.: `estampariaexpansao.com.br`) em Settings → Pages.
